# Overview

## 1. Summary

To determine if a bank customer would leave the bank, Model 1 was put into practice using Logistic Regression.
Exited was the target variable, where:
0 = retained customer
1 = customer churned or left

A test set with 2,000 observations was used to assess the model.
A confusion matrix and classification metrics were employed in the performance assessment. These metrics were used to evaluate the model's overall classification performance as well as its capacity to recognise departing customers.

AUC-ROC was employed as a model evaluation.

## 3. Evaluation Metrics

The following measures were used:
Accuracy
Precision
Recall
F1-score
Confusion Matrix
ROC-AUC

The percentage of observations that were correctly identified is known as accuracy.
The percentage of observations that are correctly classified as belonging to a class is known as precision.
The percentage of real observations in a class that were accurately identified is known as recall.
Precision and recall are integrated in the F1-score.
Instead of relying just on the final class predictions at a 0.5 classification threshold, the ROC-AUC measure assesses the model utilising its probability outputs.

## 6. Interpretation

According to the Model 1 results, 1,997 of the 2,000 observations in the test set were correctly classified by Logistic Regression.
There were just three observations that were misclassified:
1 false positive
2 false negatives

As a result, at the 0.5 classification threshold, the model achieved relatively equal classification results for both the retained (0) and exited (1) groups.
It is important, however, that these classification results should not be interpreted as evidence that the model's probability outputs are identical to those of Model 2. The class predictions are based on the selected classification threshold, whereas ROC-AUC uses the probability scores generated by the model.

## 7. ROC-AUC

ROC-AUC should be calculated from the model's predicted probabilities:

y_prob_logistic1 = model1.predict_proba(X_test_scaled)[:, 1]
auc_model1 = roc_auc_score(
    y_test,
    y_prob_logistic1
)

print("Model 1 ROC-AUC:", auc_model1)

## 8. Conclusion

Based on its confusion matrix, Model 1's accuracy on the 2,000-observation test set was 99.85%. There were two false negatives and one false positive. The probability outputs should also be taken into account using ROC-AUC, even though the classification predictions offer a crucial evaluation of model performance. As a result, even when both models generate identical class predictions at the 0.5 threshold, Model 1 and Model 2 can be compared.
