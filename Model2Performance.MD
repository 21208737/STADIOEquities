# Overview

## 1. Summary

In order to forecast if a bank customer will leave the bank, Model 2 was constructed using a Random Forest classifier.
Exited was the target variable, where:
0 = retained customer
1 = customer churned or left

A test set with 2,000 observations was used to assess the model.

A confusion matrix and classification metrics were employed in the performance assessment. Because the model generates probability estimates that may be assessed independently of the chosen 0.5 classification threshold, ROC-AUC was also taken into consideration.

## 2. Related Notebook

The Model 2 implementation and performance calculations are contained in:
statistical_helpers/Model2Performance.ipynb

How to use the notebook:
- Ensure that the required Python packages listed in requirements.txt are installed.
- Ensure that the Bank Customer Churn Dataset is available in the specified dataset directory.
- Open Model2Performance.ipynb in Jupyter Notebook or JupyterLab.
- Run the notebook cells sequentially.
- The notebook performs the Model 2 prediction and calculates the relevant performance metrics.

## 3. Evaluation Metrics

The following measures were used:
Accuracy
Precision
Recall
F1-score
Confusion Matrix
ROC-AUC

These metrics offer supplementary data regarding the classification performance of the model. Because it is not dependent on a single classification threshold, the ROC-AUC measure is very useful when comparing probability outputs.

## 4. Confusion Matrix

The model correctly classified: 1,591 + 406 = 1,997 of the 2,000 test observations.
The resulting accuracy calculated from the confusion matrix is: 99.85%

## 6. Interpretation

1,997 of the 2,000 observations in the test set were correctly classified by Random Forest, according to the Model 2 results. There were just three observations that were misclassified:
One false positive
Two false negatives

As a result, the hard-class predictions that are generated are the same as those generated by Model 1.
Nevertheless, the two models did not necessarily produce the same probability estimates if the class predictions were the same. Even if a 0.5 threshold yields the same predicted class for each observation, the probability values generated by the two models may still be different.

## 7. ROC-AUC

ROC-AUC should be calculated using the probability that the customer belongs to the exited class:

y_prob_rf2 = model2.predict_proba(X_test)[:, 1]
auc_model2 = roc_auc_score(
    y_test,
    y_prob_rf2
)

print("Model 2 ROC-AUC:", auc_model2)

Model 2 ROC-AUC: 0.5066732251946005

## 8. Conclusion

Model 2 achieved 99.85% accuracy on the 2,000-observation test set based on its confusion matrix.
The model produced:
1 false positive
2 false negatives
1,591 true negatives
406 true positives

The classification results are identical to those obtained from Model 1. However, as the classification threshold transforms continuous probability estimates into binary predictions, the probability outputs will be analysed independently using ROC-AUC.
